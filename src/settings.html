React components

On a React page, a step can record the component it happened in — and which file that component was written in, so an AI opens the right one instead of searching for it.

Record the component behind each step Costs nothing on a page that is not React — the recorder looks once, finds no React, and stops looking.
Find the file each component came from Reads the page's own scripts and source maps, from your browser cache wherever it can. Nothing is uploaded. With this off a step still names its component, it just cannot say where it lives.

Optional. The folder those files live in on this machine — it turns a recorded path into a link the viewer can open in your editor.

{path} is the absolute file path. {line1} and {col1} count from 1; {line} and {col} count from 0. It has to be an app link — an http:// or file:// template is refused.
